# Save YT Video (Frontend)

A sleek, responsive React frontend for downloading YouTube videos. Built with Vite and styled using a custom IBM Carbon-inspired design system.

## Features
- **Metadata Preview:** View video thumbnail, title, duration, and estimated file size.
- **Quality Selection:** Choose between Optimal, Best, or Custom (select specific audio and video streams).
- **Custom Location:** Set a specific local directory path to save downloads.
- **Responsive:** Fluid UI that scales perfectly across desktop and mobile screens.

## Setup & Running Locally

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```

*Note: The frontend expects the backend API to be running on `http://localhost:3000`.*
